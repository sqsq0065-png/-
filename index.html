מפתחות API סודיים לא נשמרים בדפדפן. חיבור אמיתי לסליקה/AI/WhatsApp צריך להתבצע בשרת או Edge Function.
אזור זה מיועד לניהול תוכן האתר הציבורי (שירותים, מחירים, זמינות תורים, גלריה, טקסטים) ישירות מתוך האפליקציה.
כדי שהשינויים כאן יופיעו בפועל באתר shmuelbarber.lovable.app, שני המוצרים צריכים לשתף Backend/Database אחד — ראו README (SiteIntegration) לפרטי החיבור הדרוש.
הפקת מסמך מס חוקי בישראל מחייבת חיבור לספק חיצוני מורשה (כגון Green Invoice / iCount). המסך מדגים את הזרימה בלבד.
